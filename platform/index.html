Run it yourself

Use the same path

Keep the key local, review the graph, then run the check and the execution

Keep the key local

Set KEEPERHUB_API_KEY in your shell and review the graph before execution. The graph check does not broadcast.

npm install
$env:KEEPERHUB_API_KEY = "kh_<local-only>"
npm run compose

$env:PINPOINT_WORKFLOW_ID = "w2hjt7ekrdc1lwl1grza6"
npm run verify-invariant
npm run dry-run

$env:PINPOINT_APPROVED = "1"
npm run execute
